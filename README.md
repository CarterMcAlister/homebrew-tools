# Homebrew Tools

Homebrew tap for CarterMcAlister tools.

## Setup

```sh
brew tap CarterMcAlister/tools
```

## Formulae

Install AeroSpace Layout Manager:

```sh
brew install aerospace-layout-manager
```

Install launchctrl-tui:

```sh
brew install launchctrl-tui
```

You can also install without tapping first:

```sh
brew install CarterMcAlister/tools/aerospace-layout-manager
brew install CarterMcAlister/tools/launchctrl-tui
```
