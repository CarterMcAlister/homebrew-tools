# Homebrew Tools

Homebrew tap for CarterMcAlister tools and convenient installers for selected third-party tools.

## Setup

```sh
brew tap CarterMcAlister/tools
```

## Formulae

| Formula | Description | Source |
| --- | --- | --- |
| `aerospace-layout-manager` | Layout manager for AeroSpace window manager | [CarterMcAlister/aerospace-layout-manager](https://github.com/CarterMcAlister/aerospace-layout-manager) |
| `launchctrl-tui` | Terminal UI for inspecting and controlling macOS startup items | [CarterMcAlister/launchctrl-tui](https://github.com/CarterMcAlister/launchctrl-tui) |
| `agentsview` | Local web viewer for AI agent sessions | [wesm/agentsview](https://github.com/wesm/agentsview) |

Install after tapping:

```sh
brew install aerospace-layout-manager
brew install launchctrl-tui
brew install agentsview
```

Or install without tapping first:

```sh
brew install CarterMcAlister/tools/aerospace-layout-manager
brew install CarterMcAlister/tools/launchctrl-tui
brew install CarterMcAlister/tools/agentsview
```
